# python-productivity_suite
A command-line based productivity application built using Python.  
This project includes multiple tools such as a calculator, notes manager, timer, file organizer, and unit converter.
## Features
- Calculator for basic arithmetic operations
- Notes Manager with JSON file storage
- Countdown Timer
- File Organizer for sorting files by extension
- Unit Converter (KM to Miles, Celsius to Fahrenheit)
- Menu-driven command line interface
